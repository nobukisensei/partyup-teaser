About the Project Name

プロジェクト名について

Project Name

PartyUp！

パーティアップ

「PartyUp！」の由来は、RPGやゲームの世界で使われる
「パーティを組む（Party Up）」という言葉です。

一人では倒せなかったボスも、それぞれの特技を持つ仲間が集まれば越えられる——
占い師、元アイドル、怪談好き、霊能者、魔女……
異なる「力」を持つ女性たちが集い、チームとして動き出す。

そのワクワク感と、参加する気軽さ・楽しさを込めて名づけました。
さあ、パーティを組もう。

※ ユニット正式名称は今後メンバーと共に決定します。あなたのアイデアも大歓迎です。
